1

Install LM Studio

Free desktop app for running local LLMs on Windows, macOS, and Linux.

  1. Go to lmstudio.ai and click Download.
  2. Run the installer for your OS. No GPU required, but an Nvidia or AMD GPU will significantly speed up generation.
  3. Launch LM Studio. The first run may take a moment to initialize.
💡

Minimum requirements: 16 GB RAM recommended. The model used here is ~6 GB on disk (Q4_K_S quantization) and uses roughly 6–8 GB of VRAM or RAM during inference.

3

Download and Place the mmproj Vision Adapter

Vision-language models require a separate multimodal projector file to process images.

⚠️

This step is mandatory. Without the mmproj file, the model cannot analyze images — it will only function as a text model and ignore any images you send.

  1. Download the mmproj file from HuggingFace:
    mmproj-Qwen3-VL-8B-Instruct-F16.gguf
  2. Click the download icon (↓) on the file page to download the raw .gguf file (~800 MB).
  3. Place the file in the same folder as the main model:
Target folder — both files must be here
C:\Users\<YourName>\.lmstudio\models\mradermacher\Qwen3-VL-8B-NSFW-Caption-V4.5-heretic-i1-GGUF\ ├── Qwen3-VL-8B-NSFW-Caption-V4.5-heretic-i1.Q4_K_S.gguf ← main model └── mmproj-Qwen3-VL-8B-Instruct-F16.gguf ← vision adapter
✅

LM Studio automatically detects the mmproj file when it is in the same directory as the model. You do not need to configure anything — it will load both files together.

4

Configure and Start the Local Server

LM Studio exposes an OpenAI-compatible API that the Prompt-Engineer tool connects to.

Load the model

  1. In LM Studio, click the Developer icon in the left sidebar (the </> symbol).
  2. Click Local Server in the left panel.
  3. Click Load Model (top right) and select the Qwen3-VL-8B model you downloaded.
  4. Wait for the model to load. You will see READY appear next to the model name when it is fully loaded.

Start the server

  1. In the Local Server panel, find the Status toggle and switch it to Running.
  2. Note the server address shown under Reachable at. By default it is:
Default local address
http://localhost:1234 If you need to reach it from another device on your network: http://192.168.x.x:1234 ← shown in LM Studio as "Reachable at"

Verify vision support

  1. In the model info panel on the right, check that Capabilities shows Visi... (Vision). If it only shows text, the mmproj file was not found — double-check it is in the correct folder.
  2. The Supported endpoints section should show POST /api/v1/chat as available.
💡

Parallel requests: The screenshot shows Parallel 4. This means 4 simultaneous requests are allowed. For single-user local use, setting it to 1 saves memory and improves response speed.

5

Connect the Prompt-Engineer Tool

Open the HTML file and point it at your running LM Studio server.

  1. Open prompt-engineer.html in your browser (drag it into a Chrome or Firefox window, or double-click it).
  2. In the Server Address field (top of the left sidebar), enter:
    localhost:1234
    Or if accessing from another machine on your network, use the IP address shown in LM Studio.
  3. Click Detect Model. If the connection succeeds, the model name will appear in green under the address field and the context limit will be auto-set.
  4. Select a System Prompt from the dropdown. For image captioning with this model, start with Z-Image: Caption from Image or Qwen-Image: Caption from Image.
  5. The badge below the dropdown will show the mode:
    🟢 Vision — requires image 🟡 Generate — text only 🟣 Rewrite — paste prompt
  6. For vision prompts: click the paperclip icon or drag an image into the chat area to attach it.
  7. Press Enter or click the send button. The model response streams in real time.
ℹ️

Changing system prompts automatically clears the chat history. This ensures the model always starts fresh with the new instructions rather than continuing from a previous conversation.

Troubleshooting

Common issues and how to fix them.

Connection issues
  • "Connection failed" on Detect Model — Make sure LM Studio's Local Server status is set to Running (green toggle). Check that the address in the tool matches the one shown in LM Studio.
  • Correct address format — Enter just localhost:1234 without http://. The tool adds the protocol automatically.
  • Firewall blocking — On Windows, allow LM Studio through Windows Defender Firewall if accessing from another device on your network.
Model not analyzing images
  • Vision capability not shown — The mmproj file is missing or in the wrong folder. It must be in the exact same directory as the main .gguf model file.
  • Model loaded without vision — Eject the model in LM Studio and reload it after placing the mmproj file correctly.
  • Upload button is greyed out — You have a Generate or Rewrite mode prompt selected. Switch to a Vision mode prompt (green badge).
Slow or truncated responses
  • Responses cut off early — Increase Max Tokens in LM Studio, or enter a larger Max Tokens override. Structured prompts with a Prompt block and a Negative Prompt block can exceed 512 tokens.
  • Very slow first response — Normal for vision models. The image is tiled and processed before any text is generated. A 512px image takes 2–8 seconds to process depending on your hardware.
  • Out of memory errors — Lower the image max dimension to 384px, or reduce the context window in the tool settings.
  • "top_k unsupported" errors — Clear the Top K field. Empty optional fields are omitted from requests entirely.
Context window
  • Default context — The tool defaults to 8192 tokens. After clicking Detect Model, it will use the value reported by LM Studio if available.
  • Vision token cost — A 512px image uses ~900 tokens, a 768px image uses ~1800. Add your system prompt size (~600–800 tokens for detailed prompts) and chat history to estimate total usage.
  • Context trimming — The tool automatically trims old messages when history exceeds 75% of the context window.
