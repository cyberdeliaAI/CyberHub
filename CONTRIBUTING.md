# Contributing to CyberHub

Suggestions, bug reports and focused contributions are welcome.

## Before You Start

1. Open an issue or discussion before beginning a substantial change.
2. Keep each pull request focused on one logical change.
3. Match the surrounding code style and avoid new dependencies unless they have
   been discussed first.
4. Test Gallery changes against a real image folder and test module changes on
   every operating system available to you.
5. Do not commit local settings, databases, user images, downloaded models,
   credentials or release archives.

Useful contribution areas include metadata parsers, accessibility, Gallery and
search behavior, documentation, platform startup fixes and module integrations.
